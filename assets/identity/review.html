Marks

Wordmark and glyph

Fraunces 600 / opsz 144, outlined to paths (no font dependency). The caret replaces the hyphen: a chevron rising from the hyphen band, stroke matched to the lowercase stems. wordmark.svg and glyph.svg use currentColor; the -light/-dark files bake the ink for README use.

Stamps

Evidence stamps

Five 20px seals, distinguishable by shape as well as colour: solid ring + tick; ring + double rule; dashed ring + hollow centre; dotted ring + solid dot; ring + strike. Inline (.stamp): only the icon carries the evidence colour; the label is always --ink-dim (lead decision 2026-09-02), so labels meet AA text contrast and icons are judged as graphic objects (3.0:1).

Motion

Motion

Only four motions exist. Every duration is multiplied by var(--motion), which prefers-reduced-motion: reduce sets to 0, so reduced-motion users see the final state immediately.

  • Spire draw — the spire scales up from the bottom once on load (900ms). Live on this page's left/38% line.
  • Tier reveal — the five ascent tiers fade in bottom to top, 90ms apart:
tier 5 · public proof
tier 4 · deterministic tests
tier 3 · contracts
tier 2 · fences

  • Stamp print — a stamp settles from 118% to 100% when it enters (220ms). See the stamps above (data-print).
  • Row hover — a repository row tints to ground-2 and nudges 0.35rem right (160ms):

No parallax, no continuous loops, no scroll-jacking. Nothing else animates.
